# WGU D276 Portfolio

A basic professional portfolio website created for WGU's D276 Web Development Foundations course.

The goal of this project is to demonstrate foundational HTML, CSS, and JavaScript skills while meeting the required course criteria in a clear and organized website.

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Website Pages

The portfolio contains four pages:

- `index.html` — Home
- `resume.html` — Résumé
- `cover-letter.html` — Cover Letter
- `career-goals.html` — Career Goals

All pages use a shared `style.css` stylesheet.

The résumé page also uses `script.js` for required JavaScript functionality.
